## 产品

AI + 农业，收敛到一件事：**水稻系统的碳与甲烷量化引擎**。

用过程模型加 AI，给稻田的甲烷减排和土壤固碳出一份能过第三方核证的数字，卖给需要这份数字的人。荆州提供田间数据和模型校准，加州提供收入。

完整论证见 [`product-thesis.zh-CN.md`](product-thesis.zh-CN.md)。

## 为什么是这两站

- 荆州和萨克拉门托河谷是同一类问题：水稻、灌溉、水资源约束、土壤碳与温室气体。一边验证，另一边就能复用。
- 加州有 CDFA Healthy Soils Program、合规碳市场和最密集的农业科技投资，是生物炭与土壤碳工作最容易变成生意的地方。
- 在美国读的博士、DSSAT 这个全球通用的模型框架、每天在用的 AI 智能体，三样都不需要翻译就能在加州用。
